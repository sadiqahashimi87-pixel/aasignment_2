CineVerse — Movie Discovery and Booking Website

1. PROJECT DESCRIPTION

CineVerse is a movie website where users can browse movies, explore recommendations, register, and use a demonstration ticket booking form.

2. FILES

* index.html — Home page
* movies.html — Movie listings
* recommend.html — Movie recommendations
* register.html — Registration form
* booking.html — Booking form
* css/style.css — Website styling
* css/js/script.js — JavaScript functionality
* images/ — Movie images

3. HOW TO RUN

Open index.html in a web browser. The website must also be tested on the Mercury server according to the assignment instructions.

4. BOOKING NOTICE

The booking form is a demonstration only. No real payment is processed.
